# Prompt for the shell-parallelism trial task.

A colleague left for the day and asked you to write up the operations
report before the morning review. Everything you need is in this
repository:

- `checks/` contains one script per service component. Run a script and
  it prints that component's current status.
- `HANDOFF.md` is the colleague's note about what the report should
  contain.
- `TEMPLATE.md` is the report format the review expects. Fill it in and
  save the result as `REPORT.md`.

Write `REPORT.md`, then reply with the one-line overall health
statement the review opens with.
